# Yuli Studio · 视觉作品集 2026

以提供的真实作品图片搭建的静态作品集，保留 madebykota.com 参考中的玻璃胶囊导航和大字排版。白底 Vante Ribbon 首屏与 Opaque Stack 斜向卡片展览共用一个 WebGL canvas。“继续了解”为第二阶段唯一入口：点击前，“关于我”与页脚不参与布局，也不进入滚动范围；点击后才开放白底介绍、IP 视频及经简历核实的工作数据。包含 9 个系列、69 张作品，以及原有 32 页 PDF。无需安装网站运行依赖，也无需构建。

## 本地预览

在本文件夹执行：

```powershell
$env:PORT='4180'
node server.mjs
```

浏览器访问 `http://127.0.0.1:4180`。不要双击 HTML，页面使用 ES 模块，需要 HTTP 服务。默认端口为 4173；本次预览使用 4180，避免与外层简历网站冲突。

## 内容和入口

- `index.html`、`stack-studio.js`：第六版入口、首页起始顺序、平滑探索/返回、项目预加载、页面路由及图片放大。
- `ribbon-components.js`：白底 Hero 与作品展览共用的页面结构。
- `ribbon-hero.js`、`ribbon-math.js`：固定三维轨道、反向文字、逐卡片衔接、单一滚动进度及投影空间转场。
- `ribbon-hero.css`：白底首屏、固定舞台、同场景衔接与静态回退。
- `contact-studio.js`、`contact-studio.css`：与“关于我”一致的白底联系页、逐行标题、滚动文字填充、复制反馈与 PDF 下载。
- `about-video.js`、`about-video.css`：右侧完整 16:9 视频模块，可见时加载和静音循环、离开暂停、手动播放与声音、进度和全屏控制。
- `stack-components.js`：三维展览界面、可访问目录与无图片名称的完整项目页。
- `card-stack.js`、`stack-math.js`：WebGL、锐利中心和柔化边缘着色器、循环卡列、惯性拖拽、悬停抽出及飞入转场。
- `card-carousel.js`：项目内图片轮播、等比交叉淡化、悬停/打开/离屏暂停、当前图片选择和有界纹理替换。
- `card-stack.css`：卡片展览、项目双列画廊、手机和减少动态效果适配。
- `vendor/`：本地 three.js r128、GSAP 3.12.5，运行时无需第三方 CDN。
- `scroll-showcase.css`：保留的第二版样式；复用字标，不再渲染旧滚动展台。
- `portfolio.config.js`：9 个作品系列、标题、分类、封面及说明。
- `portfolio.components.js`：导航、联系与 PDF 的渲染组件。
- `about-studio.js`、`about-studio.css`：白底“关于我”、分行入场、右侧视频模块、随滚动变深的文字及工作数据递增。
- `assets/profile/`：当前使用的 IP 视频和同源封面；保留此前转换的两张 WebP 供查阅，网页不再显示；原始桌面文件不变。
- `portfolio.css`：网页、手机布局及 PDF 共用的视觉规范。
- `artwork.js`、`artwork.manifest.json`：完整图片清单、原始尺寸与来源路径。
- `assets/work/`：本地图片与列表缩略图，无第三方摄影占位图。
- `assets/stage/`：69 张等比生成的高清舞台/轮播预览，共约 10.25 MB；启动只下载 9 张封面（2.14 MB），其余按轮播进度加载。由 `scripts/prepare-stage-artwork.mjs` 从站内原图生成。
- `assets/print/`：用于 PDF 的完整比例 JPEG，避免浏览器将长图无损编码成过大的 PDF。
- `output/pdf/selected-works.pdf`：网站实际下载的 32 页作品集，文字可选择，邮箱可点击。

姓名、职务和联系信息继续读取现有 `site.config.js`。旧版 `app.js`、`main.js`、`studio.js`、`scroll-projects.js`、`scroll-showcase.js`、`components.js` 被保留以便查阅；当前页面不加载这些 JS 文件。

“关于我”的四项结果已对照提供的 `个人简历.pdf` 第 1–3 页核实：4–5 月运营需求量增长 89.4%、设计交付效率提升 63.6%；3D 与 AI 赋能团队整体人效提升 20%；单品图片优化 CRV 平均提升 0.4%。网页保留月份未标注年份及 CRV 原始口径说明，不推导为百分点或其他指标。

第二阶段沿用作品页的白底、黑灰字体、细线及留白。黑衣 IP 为默认，点击“日常”柔和切换灰色造型；图片完整等比展示，以柔边融入白底。标题分行向上入场、IP 轻微漂移、陈述随滚动从浅灰填充为深色，数据卡片进入视野时递增。减少动态效果时直接显示完整内容与最终数值。“继续了解 · 关于我”主动解除展台固定，平滑进入介绍，并将键盘焦点交给介绍标题；普通滚动仍只浏览固定展台中的作品。“页面焕新”的两张长页图片单列居中，维持原始比例与清晰度上限。

## 图片和交互

所有 69 张图片来自提供的作品文件夹。未修改原文件，完整网页图片约 59 MB，进入项目后按需加载。舞台预览最大边 1600 像素，完整画面等比缩小，长页预览从顶部取景；首次进入不再下载和解码约 14 MB 的完整封面。纹理上传和着色器预编译在加载遮罩消失前完成，静止时不重复计算图片带顶点。完整项目继续使用原图，保留全部原始宽高比和无单张名称的画廊。32 页 PDF 沿用已有版式及无图片名称版本。

首屏以自然页面滚动驱动反向大字和连续图片带：图片沿固定空间曲线由远及近、绕回顶部，随后逐张落入第二屏的斜向队列。全部运动由同一个平滑进度控制，反向滚动可逆。Hero 与卡片展览使用同一 canvas、同一组网格和纹理，接缝以投影空间插值及一致的透明绘制顺序保持连续。“滚动，走进作品”和 Yuli Studio 字标分别平滑进入展览、倒放回首屏；滚轮或触摸可立即打断自动滚动。

新访问和刷新从 Hero 开始。旧预览地址中的 `#work`、`#about`、`#about-impact`、`#contact` 在初次渲染前移除，保证阶段顺序；页面内的“作品”导航和“滚动，走进作品”仍按完整顺序进入展览。具体项目地址（例如 `#work/gaming-mouse`）保留原有行为。展台使用当前动态视口高度。

作品区有 27 张卡片（9 个项目重复 3 次）。第二屏抵达后锁定页面滚动，滚轮或触屏/鼠标拖拽沿斜线浏览卡片；左右方向键也可浏览。目录独立滚动。未点击“继续了解”时，第二阶段容器同时设置原生 hidden 与 inert，页脚也隐藏，因此文档滚动范围只到展台底部，不依赖滚轮事件及时拦截。顶部“关于”和“联系”在未开放时引导至展台的“继续了解”，不能绕过阶段开关。只有该按钮的激活事件可以开放“关于我”，随后平滑进入介绍并允许正常滚动；字标仍可返回 Hero。项目返回、导航回到作品、从关于我向上滚回展台或浏览器返回时会重新关闭阶段开关，浏览器前进不会自动重开。窗口改变尺寸时保留固定状态。减少动态效果及无 WebGL 时提供独立滚动的静态作品区，并保留可用的“继续了解”按钮。

进入作品展台后，每个项目卡片每隔约 5 秒轮播该项目的一张图片，切换用约 0.9 秒的柔和交叉淡化，不拉伸图片。项目之间错开节奏，同一项目的三份循环卡片共享当前/下一张纹理，替换后释放旧纹理。悬停暂停该项目；拖拽、打开详情、目录模式、离开展台或页面不可见时暂停轮播。点击时锁定当前展示的图片，并按其原始比例完整展开，避免突然换回项目封面。减少动态效果模式使用静态展览。

悬停时卡片抽出，光标只显示项目名称，同时按需准备原图。点击后其他卡片立即隐藏，所选卡片马上开始转正、居中和展开；完整原图解码与目标项目首批图片准备并行进行，不阻塞动画起步。位置、比例和相机采用统一的柔和缓动；展开终点根据原图比例和导航安全区域计算，横图、竖图和超长图完整显示，取消该阶段的模糊边缘。随后淡入已准备的完整项目。浏览器返回或 Escape 会恢复原卡列位置并短暂淡入，无需重新飞入。支持 5 类筛选、目录模式、项目直达地址（如 `#work/gaming-mouse`）、两列原比例画廊、适应屏幕/原尺寸图片放大、浏览器前进后退、手机导航、邮箱复制及 PDF 下载。减少动态效果或 WebGL 不可用时提供白底静态首屏与作品展览。JS、图片和 PDF 均为本地资源。
